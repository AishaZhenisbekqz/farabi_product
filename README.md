# FARABI PRODUCT — фронтенд-прототип (HTML / CSS / JS)

Цифровая витрина коммерциализации КазНУ по ТЗ (`TZ_FARABI_PRODUCT.docx`). Без фреймворков и сборки.

## Запуск
```bash
python -m http.server 5510
```
Открыть http://localhost:5510 (можно и просто открыть `index.html` двойным кликом).

## Структура
| Файл | Что внутри |
|---|---|
| `index.html` | каркас страницы, SEO-мета |
| `css/styles.css` | дизайн-система, адаптив (десктоп / планшет / телефон), админка |
| `js/data.js` | демо-данные: продукты, AI, патенты, книги, учёные, ответственные, заявки |
| `js/i18n.js` | интерфейс KZ / RU / EN, справочники (категории, статусы, цепочка готовности) |
| `js/store.js` | «бэкенд» на localStorage: поиск, заявки, аналитика, журнал действий |
| `js/ui.js` | карточки, контакт ответственного, «Где купить», модалки, форма заявки, SEO |
| `js/views.js` | страницы: главная, каталоги, карточки, поиск, учёный, «Для бизнеса», «О КазНУ», контакты |
| `js/admin.js` | админ-панель: аналитика, CRUD, заявки + CSV, категории, настройки, журнал |
| `js/app.js` | роутер (`#/products/nanoquqyrt`) и обработчики событий |

## Админ-панель
`#/admin` — в демо вход по выбору роли (суперадмин / Центр коммерциализации / учёный — видит только свои разработки).
Данные сохраняются в браузере; «Настройки → Reset» возвращает демо-данные.

## Что остаётся для бэкенда (этап 2)
Серверная авторизация и права доступа, БД и файловое хранилище, реальные e-mail/Telegram-уведомления,
URL без `#` (`/products/nanoquqyrt`) с серверным рендерингом для индексации, резервное копирование, защита от XSS/CSRF/SQLi/brute-force.
